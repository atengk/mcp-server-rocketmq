# 分流与分类标签字典 (Triage Labels)

工程技能遵循五大标准分流角色。本文件记录当前仓库 GitHub Issues 实际映射的标签定义：

| 规范角色 (Canonical Role) | 当前仓库标签 (Label in Tracker) | 说明与含义 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 待维护者评估与分流 |
| `needs-info` | `needs-info` | 阻塞中，等待提报者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 需求与契约完全清晰，可由离线 Agent 独立实现 |
| `ready-for-human` | `ready-for-human` | 需要人工决策或人工介入实现 |
| `wontfix` | `wontfix` | 确认不予处理/关闭 |

当技能提及某一角色（如“打上 AFK-ready 离线执行标签”）时，使用本表中对应的标签字符串。
